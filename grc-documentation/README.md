## Project Overview

This project covers the design and implementation of a Cybersecurity GRC program for an enterprise environment. The work focuses on establishing a governance structure, conducting risk assessments, and mapping organizational controls to regulatory compliance requirements — using internationally recognized frameworks throughout.

## Frameworks & Standards Applied

**Governance**

- NIST Cybersecurity Framework (CSF) — Identify, Protect, Detect, Respond, Recover
- ISO/IEC 27001 — Information Security Management System structure
- COBIT — IT governance and management alignment
- CIS Controls — Prioritized security control implementation

**Risk Management**

- ISO 31000 — Risk management principles and guidelines
- NIST SP 800-30 — Risk assessment methodology
- FAIR Model — Quantitative risk analysis

**Compliance**

- GDPR — Personal data protection requirements
- PCI DSS — Payment card data security
- DORA — Digital operational resilience (financial sector)
- ePrivacy Directive — Electronic communications privacy

-----

## What Was Covered

The implementation followed a five-phase approach:

1. **Program Initiation** — Defined scope, governance structure, and stakeholder roles
1. **Risk Assessment** — Identified and rated organizational risks using NIST SP 800-30 and FAIR
1. **Risk Treatment Planning** — Mapped risks to controls and defined accept/mitigate/transfer decisions
1. **Control Implementation** — Aligned controls to ISO 27001 Annex A and CIS Controls
1. **Monitoring & Improvement** — Established KPIs, audit cycles, and continuous review process
